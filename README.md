# 🎮 Clone PlayStation Store — Bootstrap 5

Projeto desenvolvido como exercício prático utilizando Bootstrap 5 para recriação de uma página institucional inspirada na PlayStation Store.

O foco foi aplicar o grid system, componentes interativos e customizações visuais mantendo a estrutura do framework.

---

## 🎯 Objetivo

- Praticar o uso do Bootstrap 5
- Trabalhar com componentes prontos do framework
- Aplicar customizações via CSS
- Construir layout responsivo baseado em breakpoints

---

## 🛠 Tecnologias Utilizadas

- HTML5
- Bootstrap 5.3 (via CDN)
- CSS3
- Font Awesome

---

## 🧩 Componentes Implementados

- Navbar responsiva com Collapse
- Dropdown menus
- Carousel com legendas
- Tabs com navegação dinâmica
- Grid responsivo com `row-cols-*`
- Cards de catálogo organizados por categoria

---

## 🎨 Customizações Aplicadas

- Sobrescrita de variáveis `--bs-btn-*` para estilização de botões
- Gradiente animado com `@keyframes`
- Ajustes de responsividade adicionais via media queries
- Scrollbar customizada
- Ajustes visuais no carousel e nas imagens do catálogo

---

## 📱 Responsividade

- Breakpoints nativos do Bootstrap
- Ajustes adicionais para 1200px, 1023px e 768px
- Reorganização de colunas conforme o tamanho da tela

---

## ▶️ Como Executar

1. Clone o repositório
2. Abra o arquivo `index.html` no navegador
3. Bootstrap é carregado via CDN

---

## 📌 Observação

Projeto desenvolvido com finalidade educacional para prática de utilização estruturada do framework Bootstrap.
